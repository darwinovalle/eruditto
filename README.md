# Eruditto

A free, lightweight clipboard manager for Ubuntu inspired by Ditto Clipboard Manager.

## Features

- Clipboard history (text and images)
- Instant search (SQLite FTS5)
- Global hotkey (Ctrl+Shift+V)
- Favorites / pinned clips
- System tray
- Configurable settings

## Requirements

- Linux (X11 or Wayland via XWayland)
- Go 1.25.5+
